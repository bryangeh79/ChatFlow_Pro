# ChatFlow Pro

AI reception and customer-support automation for SMEs.

## Deliverable runtime (this repo)

Production path: Node server under `src/` (seven webhooks, unified pipeline, outbound send). **Go-live checklist (2-day):** **`docs/168_pro_two_day_go_live_checklist.md`**. **Commercial model (one customer = one deployment):** **`docs/169_pro_commercial_one_customer_one_deploy.md`**. Module intent: **`docs/01_module_blueprint.md`**.

## Structure
- `frontend/` chat widget and admin UI skeleton
- `backend/` modular API and service skeleton
- `shared/` shared types, constants, interfaces
- `i18n/` language resource skeleton
- `docs/` product and architecture documentation
- `memory/` project state and handoff notes
