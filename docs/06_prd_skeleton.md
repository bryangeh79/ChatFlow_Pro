# 06 PRD Skeleton

## 1. Product Overview
ChatFlow Pro is an AI-enabled customer reception and support automation system for SMEs.
It handles inbound conversations, knowledge-based replies, lead capture, collaboration, handoff, and basic reporting.

## 2. Product Boundary
### In Scope
- Website chat
- Telegram
- WhatsApp
- Facebook Messenger
- Automated reception
- FAQ and knowledge base replies
- Lead capture
- Multi-user collaboration
- Human handoff
- Notifications
- Basic reports
- Admin console

### Out of Scope
- Shopee
- Lazada
- TikTok Shop
- Other e-commerce platform integrations
- Payment processing
- ERP integration
- Full order management
- Advanced sales pipeline automation
- Enterprise-level CRM replacement

## 3. Product Positioning
- Designed for SMEs that need 24/7 first-line customer reception.
- Focused on communication and support automation, not commerce execution.
- Built to reduce manual response load and capture qualified leads.

## 8. Multilingual Strategy
- Phase 1 supports four languages:
  - Chinese
  - English
  - Vietnamese
  - Malay (Malaysia)
- Phase 1 scope is strategy, field reservation, content layering, and structure planning.
- Phase 1 does not implement full translation packs.
- The data model and UI should reserve language-aware fields from the start.
- Future language expansion should be possible without redesigning core modules.
