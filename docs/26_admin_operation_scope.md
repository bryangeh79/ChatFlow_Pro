# 26 Admin Operation Scope

## Admin Can Operate
- Create FAQ items
- Edit FAQ items
- Disable / stop FAQ items
- View conversation records
- View messages in a conversation
- View handoff summary information
- View lead basic profile data
- View basic statistics
- Edit minimal system settings

## Admin Read-Only Areas
- Conversation and message history
- Handoff summary history
- Basic report output
- Assignment state visibility

## Future Staff / Sales Visibility
- Staff and sales members may later view assigned conversations and customer basics.
- This phase does not build a full role matrix.
- Their operational surface remains minimal and not deeply implemented.

## Explicitly Delayed
- Complex permission matrix
- Bulk editing flows
- Advanced report configuration
- Deep notification control
- Channel management expansion
