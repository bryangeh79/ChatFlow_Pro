# 20 Handoff Summary Spec

## Goal
Produce a small, useful summary that helps a human staff member continue the conversation without rereading everything.

## Minimum Fields
- conversationId
- languageCode
- channel
- latestUserIntent
- latestMessages
- currentOwnerMemberId
- fallbackOccurred
- generatedAt

## Summary Source
The summary is generated by the handoff summary service.
It should be rule-based, not AI-generated in this phase.

## When It Is Generated
- When a handoff is triggered
- Immediately before the conversation is passed to a human

## How It Is Used
- It is shown or passed to the next human staff member before takeover.
- It provides a fast context snapshot.

## Future Reuse
If database, notifications, or backend admin views are added later, the same summary object can be stored, displayed, or forwarded without redesigning the handoff concept.
