# 25 Admin Minimal Pages

## Goal
Define the smallest backend/admin surface for ChatFlow Pro.
The admin area is a management and viewing layer, not a new business-state source.

## MVP Required Pages

### 1) FAQ / Knowledge Base Management
#### Goal
Manage support content used by the runtime reply flow.

#### Minimum Blocks
- FAQ list
- language filter
- create/edit form
- active/inactive toggle
- keyword/tag fields

### 2) Customer / Lead Detail Page
#### Goal
View the basic profile of a customer or lead.

#### Minimum Blocks
- identity block
- contact block
- inquiry summary
- language/channel info
- ownership / assignment info

### 3) Conversation Record Page
#### Goal
Inspect the conversation history and status.

#### Minimum Blocks
- conversation header
- message timeline
- language/channel badge
- assignment/handoff status block
- linked lead block

### 4) Basic Reports Page
#### Goal
Show simple operational counts.

#### Minimum Blocks
- summary metrics cards
- daily/weekly trend section
- top questions section
- handoff count section

### 5) System Settings Page
#### Goal
Manage the minimum system configuration.

#### Minimum Blocks
- welcome message
- default language
- basic rule placeholders
- operating hours placeholder

## MVP Must-Have Pages
- FAQ / Knowledge Base Management
- Customer / Lead Detail
- Conversation Record
- Basic Reports
- System Settings

## Reserved for Later
- Advanced analytics
- Template library
- Permission matrix editor
- Deep notification settings
- Channel configuration console expansion
