## Pages Related to Language
- Welcome state and entry chat page: language-aware display
- Chat interface: language-specific rendering and reply selection
- FAQ management: content can be stored by language
- Knowledge base management: content can be stored by language
- Auto reply rules: rules can include default language behavior
- System settings: default language and fallback policy
- Reports: may later group by language, but not required in Phase 1

## Admin Surface Summary
### Must-have admin surfaces
- Dashboard
- Conversations
- Customers
- Leads
- FAQ / Knowledge Base
- Auto Replies
- Channels
- Team Members
- Permissions
- Reports
- System Settings

### Reserved admin surfaces for later
- Advanced language analytics
- Template library expansion
- More granular per-channel language mapping

## Scope Note
This list is intentionally limited to reception, support, and internal operations.
It does not include storefront, checkout, order management, payment, or e-commerce admin panels.
