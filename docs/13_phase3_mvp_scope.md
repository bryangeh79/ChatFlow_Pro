# 13 Phase 3 MVP Scope

## Phase 3 Purpose
Build the first working conversation MVP for ChatFlow Pro.
The goal is a minimal, stable, language-aware conversation loop with a place to connect FAQ / knowledge base replies later.

## What This MVP Includes
- Website chat bootstrap
- Session / conversation initialization
- Minimal language resolution
- Minimal message intake
- Minimal response dispatch
- Shared type alignment between frontend and backend
- Placeholder structure for FAQ / knowledge base hookup

## What This MVP Does Not Include
- Real Telegram, WhatsApp, or Facebook Messenger webhook integration
- Complex FAQ retrieval logic
- Knowledge base search algorithms
- Database migration work
- Deep admin workflows
- Full role / permission logic
- Any e-commerce, payment, ERP, or sales-closure feature

## Next Hook After MVP
The next step after the minimal loop is to connect:
- FAQ items
- knowledge base records
- language-aware answer selection
- fallback reply behavior

## Multilingual Scope in Phase 3
- Support the four locked languages structurally:
  - zh
  - en
  - vi
  - ms-MY
- Use language resolution and fallback logic
- Keep language handling rule-based and lightweight
- Do not build a full translation platform in this phase

## Later Phase Split
### Phase 4
- Multi-user collaboration
- Human handoff
- Assignment and summary transfer

### Phase 5
- Admin management surfaces
- Reports and operational visibility

### Phase 6
- Multi-channel integration closure for Telegram, WhatsApp, and Facebook Messenger

## Phase 3 Success Definition
Phase 3 is successful when a website visitor can enter, create or reuse a session, get a language-aware minimal reply, and leave a clean path for FAQ / knowledge base integration.
